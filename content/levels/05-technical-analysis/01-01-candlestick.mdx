## 한 줄로

<Term>캔들차트</Term>는 시가(Open)·고가(High)·저가(Low)·종가(Close)의 4가지 가격을 하나의 봉으로 시각화해, 특정 기간 동안 매수·매도 세력의 공방을 한눈에 보여주는 차트다.

## 왜 알아야 하나

가격 차트를 읽는 것은 기술적 분석의 가장 기본적인 행위이며, 캔들차트는 전 세계적으로 가장 널리 쓰이는 가격 표시 방식이다. 18세기 일본의 쌀 거래에서 시작된 캔들은 4개의 숫자를 하나의 도형으로 압축해, 그날 시장에서 벌어진 '이야기'를 전달한다.

## 개념

**캔들의 구조:**

```
      │  ← 위꼬리 (Upper Shadow)
    ┌─┤  ← 고가(High)
    │ │
    │ │  ← 몸통 (Body)
    │ │     양봉: 시가→종가 (상승)
    │ │     음봉: 종가→시가 (하락)
    └─┤  ← 저가 또는 시가/종가
      │  ← 아래꼬리 (Lower Shadow)
      │
```

- **양봉** — 종가 > 시가. 매수 세력이 이긴 날. 보통 빨간색(한국) 또는 초록색(미국)
- **음봉** — 종가 < 시가. 매도 세력이 이긴 날. 보통 파란색(한국) 또는 빨간색(미국)
- **도지** — 종가 ≈ 시가. 매수·매도 세력이 팽팽. 추세 전환 가능성의 단서

**캔들 각 부분이 말하는 것:**

| 부분 | 의미 |
|------|------|
| 긴 몸통 | 한쪽 세력의 압도적 우위 |
| 짧은 몸통 | 공방이 팽팽, 방향 불확실 |
| 긴 위꼬리 | 장중 올랐지만 매도 압력에 밀려 내려옴 |
| 긴 아래꼬리 | 장중 빠졌지만 매수 세력에 의해 반등 |
| 꼬리 없는 양봉(마루보즈) | 시가=저가, 종가=고가. 시종일관 매수 우위 |

**색상 주의:** 한국과 미국의 양봉·음봉 색상이 반대다. 한국은 양봉=빨강(상승), 음봉=파랑(하락)이고, 미국은 양봉=초록, 음봉=빨강이다. HTS 설정에서 확인하고 혼동하지 않도록 한다.

## 비유로 이해하기

캔들 하나는 축구 경기의 스코어보드와 같다. 시가는 경기 시작 시 분위기, 종가는 최종 스코어, 고가·저가는 경기 중 최대 리드 폭이다. "3-1로 시작해 2-3까지 밀렸다가 4-3으로 역전승"이라는 드라마가 하나의 캔들에 압축되어 있다.

## 실제 시장에서는

2020년 3월 코로나 폭락장에서, 3월 23일 KOSPI 일봉에 긴 아래꼬리가 달린 양봉이 출현했다. 장중 1,430까지 급락했지만 종가는 1,482로 반등하며 저점을 확인했다. 이후 KOSPI는 반년간 반등해 2,300을 넘었다. 물론 그 캔들이 나왔을 때 "이것이 저점"이라고 확신하기는 불가능했다 — 캔들은 힌트이지 답이 아니다.

## 흔한 오해

**"양봉이면 좋고 음봉이면 나쁘다."** 상승 추세에서 나타나는 소폭 음봉(이익 실현)은 건강한 조정이고, 하락 추세에서 나타나는 양봉(데드캣 바운스)은 추가 하락의 전조일 수 있다. 개별 캔들보다 캔들이 나타나는 맥락(추세, 위치, 거래량)이 더 중요하다.

**"캔들 패턴만으로 매매할 수 있다."** 단일 캔들이나 2~3개 캔들 조합(5-4-4)은 확률적 신호일 뿐이다. 연구에 따르면 캔들 패턴 단독의 승률은 50~55% 수준으로, 동전 던지기보다 약간 나은 정도다. 추세·거래량·지지/저항과 함께 봐야 유의미한 판단이 된다.
