## 한 줄로

파이썬은 트레이더가 대량 데이터 분석, 전략 백테스트, 자동화를 수행하는 핵심 도구이며, pandas로 시계열 데이터를 다루고, yfinance(미국)와 pykrx(한국)로 주가 데이터를 수집하는 것이 첫걸음이다.

## 왜 알아야 하나

Level 0~9까지 트레이딩의 전 과정을 손으로 배웠다. Level 10은 이 과정을 코드로 자동화하고 확장하는 단계다. 수동으로 10종목을 분석하는 것과, 코드로 500종목을 분석하는 것의 차이는 전략의 깊이와 신뢰도에서 나타난다.

## 개념

**파이썬 학습 로드맵 (트레이더 맞춤):**

1단계 — 기초 문법 (1~2주):
- 변수, 자료형, 조건문, 반복문, 함수
- 리스트, 딕셔너리
- 파일 입출력
- 추천: 코딩 경험 없으면 "점프 투 파이썬" 또는 "파이썬 코딩 도장"

2단계 — pandas 핵심 (1~2주):
- DataFrame 생성, 인덱싱, 필터링
- 시계열 인덱스, 리샘플링
- rolling(), pct_change(), cumsum(), shift()
- 여러 종목 데이터 병합 (merge, concat)

3단계 — 데이터 수집 (1주):
- yfinance: `yf.download("AAPL", start="2020-01-01")`
- pykrx: `stock.get_market_ohlcv("20200101", "20241231", "005930")`
- 네이버 금융 크롤링 (requests + BeautifulSoup)

4단계 — 시각화 (1주):
- matplotlib 기본 차트
- 캔들차트 (mplfinance)
- 이동평균, 볼린저밴드 오버레이

**간단한 코드 예시 — 20일 이동평균:**

```python
import yfinance as yf
import matplotlib.pyplot as plt

# 데이터 다운로드
df = yf.download("SPY", start="2023-01-01", end="2024-01-01")

# 20일 이동평균 계산
df["MA20"] = df["Close"].rolling(20).mean()

# 차트
df[["Close", "MA20"]].plot(figsize=(12, 6))
plt.title("SPY with 20-day MA")
plt.show()
```

이 7줄이 엑셀에서 수십 분이 걸리는 작업을 대체한다.

**주의사항:**

- 데이터 품질: 무료 데이터에는 수정주가, 배당, 액면분할 처리가 누락될 수 있다. 분석 전에 데이터를 검증한다.
- 과최적화 위험: 코드로 대량 조합을 쉽게 테스트할 수 있지만, 이것이 6-4-2에서 배운 과최적화의 함정을 키울 수 있다.

## 비유로 이해하기

수동으로 흙을 파는 것(엑셀)과 굴삭기를 운전하는 것(파이썬)의 차이다. 굴삭기 운전을 배우는 데 시간이 걸리지만, 한번 배우면 작업 규모와 속도가 근본적으로 달라진다.

## 실제 시장에서는

글로벌 헤지펀드의 대부분이 파이썬을 핵심 도구로 사용한다. 투시그마(Two Sigma), AQR 등 퀀트 펀드는 물론, 전통적 재량 트레이더도 데이터 분석에 파이썬을 활용한다. 한국에서도 개인 퀀트 투자자가 pykrx와 pandas를 활용해 팩터 투자, 백테스팅, 자동 리밸런싱을 구현하는 사례가 늘고 있다.

## 흔한 오해

**"코딩을 못하면 퀀트 투자를 할 수 없다."** 코딩 없이도 TradingView Pine Script, 구글 스프레드시트, 전용 플랫폼(퀀트킹 등)으로 기본적인 퀀트 분석이 가능하다. 파이썬은 범위를 넓히는 도구이지 필수 조건이 아니다.

**"파이썬을 배우면 바로 돈을 벌 수 있다."** 파이썬은 도구일 뿐이며, 좋은 전략 없이 코드만 작성하면 "나쁜 전략을 더 빠르게 실행"하는 것에 불과하다. Level 6~9의 기초가 먼저다.
