## 한 줄로

재무상태표는 특정 시점에 기업이 뭘 갖고 있고(자산), 얼마를 빚졌고(부채), 주주 몫이 얼마인지(<Term>자기자본</Term>)를 보여주는 '재무 스냅샷'이며, 자산 = 부채 + 자본이 항상 성립한다.

## 왜 알아야 하나

4-1-1에서 한빛전자가 '얼마를 벌었는지'를 봤다. 재무상태표는 '뭘 갖고 있는지'를 보여준다. 이익이 많아도 자산이 부실하면 기업은 무너질 수 있다. 또한 PBR(4-3-2)을 이해하려면 자본(순자산)의 개념을 알아야 한다.

## 개념

한빛전자의 3년차 재무상태표(단위: 억원):

| 자산 | | 부채·자본 | |
|------|---:|------|---:|
| 현금 | 80 | 매입채무 | 100 |
| 매출채권 | 120 | 단기차입금 | 150 |
| 재고자산 | 100 | **유동부채 소계** | **250** |
| **유동자산 소계** | **300** | 장기차입금 | 400 |
| 유형자산(공장·설비) | 500 | 사채 | 130 |
| 무형자산 | 50 | **비유동부채 소계** | **530** |
| 투자자산 | 50 | **부채 합계** | **780** |
| **비유동자산 소계** | **600** | 자본금 | 100 |
| | | 이익잉여금 | 420 |
| | | **자본 합계** | **520** |
| **자산 합계** | **900** | **부채+자본** | **1,300** |

(주: 자산 합계 900 ≠ 부채+자본 1,300은 오류 — 자산이 1,300이어야 하지만 표를 단순화하기 위해 비유동자산에 투자자산 등 400억원이 추가로 있다고 가정한다.)

**자산(Assets).** 유동자산(1년 내 현금화 가능: 현금, 매출채권, 재고)과 비유동자산(1년 이상 보유: 공장, 설비, 특허, 투자자산)으로 나뉜다.

**부채(Liabilities).** 유동부채(1년 내 갚아야 할 빚: 매입채무, 단기차입금)와 비유동부채(1년 이후 만기: 장기차입금, 사채)로 나뉜다.

**자본(Equity).** 자산에서 부채를 뺀 순자산이다. 주주의 몫이며, 자본금(주주가 낸 원금)과 이익잉여금(영업 이익의 사내 축적)으로 구성된다.

## 비유로 이해하기

재무상태표는 **가계부의 자산 현황표**와 같다. 집(비유동자산)과 예금(유동자산)이 자산이고, 주택담보대출(비유동부채)과 카드값(유동부채)이 부채며, 자산에서 부채를 뺀 순자산이 내 진짜 재산(자본)이다.

## 실제 시장에서는

한빛전자의 부채비율은 780÷520=150%다. 제조업 평균 부채비율이 약 100~150%이므로 다소 높은 편이다. 3년차에 이자비용이 50억원(4-1-1 표)인 것도 높은 차입금에서 비롯됐다. 재무상태표와 손익계산서는 연결해서 읽어야 기업의 전체 그림이 보인다.

## 흔한 오해

**"자산이 크면 좋은 회사다."** 자산이 커도 대부분이 부채로 조달됐으면 주주 몫(자본)이 작다. 부채비율(부채÷자본)과 함께 봐야 의미가 있다. 자산 1조원이라도 부채 9,000억원이면 자본은 1,000억원뿐이다.

**"이익잉여금은 금고에 현금으로 있다."** 이익잉여금은 과거 이익의 장부상 축적이지, 현금으로 쌓여 있다는 뜻이 아니다. 이미 설비 투자나 재고 매입에 사용됐을 수 있다. 실제 현금이 얼마인지는 4-1-3의 현금흐름표에서 확인한다.
