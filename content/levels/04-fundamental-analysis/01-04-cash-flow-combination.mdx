## 한 줄로

영업·투자·재무 현금흐름의 부호 조합(+/-/-, -/+/+ 등)으로 기업의 생명주기와 재무 건전성을 한눈에 파악하며, <Term>FCF</Term>(잉여현금흐름)는 기업이 자유롭게 쓸 수 있는 진짜 여유 현금이다.

## 왜 알아야 하나

4-1-3에서 현금흐름표의 구조를 배웠다. 하지만 숫자 하나하나보다 세 영역의 부호 조합이 기업의 전체 상태를 더 빠르게 보여준다. "이 회사가 성장기인가, 안정기인가, 위기인가"를 현금흐름 조합으로 즉시 판단할 수 있다.

## 개념

**8가지 조합과 해석:**

| 영업 | 투자 | 재무 | 해석 |
|:---:|:---:|:---:|------|
| + | - | - | 우량형: 벌어서 투자하고 빚 갚음 |
| + | - | + | 성장형: 벌면서 빚도 내서 적극 투자 |
| + | + | - | 구조조정형: 벌면서 자산 팔아 빚 갚음 |
| + | + | + | 드문 케이스: 모든 곳에서 현금 유입 |
| - | - | + | 스타트업형: 적자에 투자하며 외부 자금 의존 |
| - | + | + | 위기형: 적자에 자산 팔고 빚 내서 연명 |
| - | + | - | 축소형: 적자에 자산 팔아 빚 갚음 |
| - | - | - | 극한 위기: 모든 곳에서 현금 유출 |

한빛전자 3년차는 **+/-/+**(성장형)이다. 영업에서 120억을 벌었지만 투자에 150억을 쓰고 부족분을 차입(+50억)으로 메웠다.

**잉여현금흐름(FCF).** 영업현금흐름 - 자본적 지출(CAPEX). 한빛전자: 120 - 160 = -40억원. FCF가 마이너스이면 영업에서 번 것만으로는 설비 투자를 감당하지 못한다는 뜻이다. FCF가 지속적으로 양수인 기업이 배당·자사주 매입·부채 상환의 여력이 있다.

**생명주기와 현금흐름.** 스타트업(-/-/+) → 성장기(+/-/+) → 안정기(+/-/-) → 쇠퇴기(+/+/-). 기업이 어떤 단계에 있는지를 현금흐름 조합으로 추정할 수 있다.

## 비유로 이해하기

현금흐름 조합은 **건강 검진표**와 같다. 혈압(영업)·체중(투자)·혈당(재무)을 개별로 보는 것보다, 세 가지의 조합으로 "이 사람이 건강한가, 비만인가, 위험한가"를 종합 판단하는 것이다.

## 실제 시장에서는

한빛전자의 FCF가 -40억원이라는 점은 주목할 만하다. 성장을 위한 일시적 투자인지, 구조적으로 현금이 부족한 것인지를 판단하려면 투자의 목적과 향후 매출 증가 가능성을 함께 봐야 한다. 1년차와 2년차의 FCF도 계산해서 추세를 확인하는 것이 중요하다. 참고로 1년차 영업현금흐름 95, CAPEX 80이면 FCF +15억원, 2년차 영업 140, CAPEX 120이면 FCF +20억원이었다. 3년차에 FCF가 마이너스로 전환된 것은 투자 규모가 급증한 것이 원인이다.

## 흔한 오해

**"FCF가 마이너스이면 나쁜 기업이다."** 아마존은 2012~2015년 FCF가 극히 낮거나 마이너스였지만, 대규모 물류센터·AWS 인프라 투자를 하고 있었다. 성장 투자에 의한 일시적 마이너스와 구조적 현금 부족은 구별해야 한다.

**"현금흐름 조합만으로 투자 결정을 할 수 있다."** 조합은 1차 필터이지 최종 판단 도구가 아니다. 같은 +/-/+ 기업이라도 투자의 질(불필요한 인수 vs 핵심 설비 확충)에 따라 결과가 완전히 다르다.
