## 한 줄로

1-Pager는 투자 아이디어를 한 장에 구조화해, 왜 사는지·얼마가 적정인지·언제 파는지·내가 틀릴 수 있는 시나리오가 무엇인지를 명확히 정리하는 투자자의 기본 문서다.

## 왜 알아야 하나

Level 4 전체에서 재무제표, 지표, 밸류에이션, 공시, 산업 분석을 배웠다. 이 모든 것을 종합해 하나의 투자 판단으로 모으는 과정이 1-Pager다. 도구를 배웠으니 이제 '실전에서 어떻게 조합하는가'를 연습한다. 1-Pager를 쓰지 않고 투자하는 것은 설계도 없이 건물을 짓는 것과 같다.

## 개념

**1-Pager 템플릿:**

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[기업명]  |  [업종]  |  작성일: YYYY-MM-DD
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 한 줄 요약
이 기업에 투자하는 이유를 1문장으로.

■ 사업 개요
- 무엇을 팔아서 돈을 버는가 (핵심 매출원)
- 시장 규모와 성장률
- 경쟁 구도 (점유율, 주요 경쟁사)
- 해자 유형: [브랜드 / 네트워크 / 전환비용 / 규모 / 없음]

■ 핵심 재무 (최근 3년)
| 지표 | 1년차 | 2년차 | 3년차 |
|------|------:|------:|------:|
| 매출 |       |       |       |
| 영업이익률 |  |    |       |
| ROE  |       |       |       |
| FCF  |       |       |       |
| 부채비율 |   |       |       |

■ 밸류에이션
- 현재 PER / PBR / EV/EBITDA
- Peer 평균 대비 할인/프리미엄
- 적정가치 추정 (방법: _____)
- 안전마진: ____%

■ Bull Case (강세 시나리오)
1.
2.
3.

■ Bear Case (약세 시나리오)
1.
2.
3.

■ 촉매 (Catalyst)
- 가치 재평가를 촉발할 구체적 사건/시점

■ 리스크 관리
- 손절 기준: [조건]
- 포지션 크기: 포트폴리오의 ____%
- 모니터링 항목: [분기마다 확인할 지표]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**작성 시 핵심 원칙:**

1. **한 줄 요약을 가장 먼저 쓴다.** 한 문장으로 요약할 수 없다면 아이디어가 아직 정리되지 않은 것이다.

2. **Bull Case와 Bear Case를 동등한 비중으로 쓴다.** 자신의 아이디어에 반대하는 논거를 구체적으로 적어야 확증편향을 방지한다.

3. **촉매를 반드시 포함한다.** 4-3-6에서 배운 것처럼, 촉매 없는 저평가는 가치 함정일 수 있다.

4. **손절 기준을 미리 정한다.** "Bear Case의 2번이 현실화되면 매도"처럼 조건을 구체적으로 적는다. Level 7(리스크 관리)에서 포지션 사이징과 함께 자세히 다룬다.

5. **날짜를 쓴다.** 시간이 지나면 판단의 전제가 바뀔 수 있으므로, 작성 시점을 기록하고 정기적으로 업데이트한다.

## 비유로 이해하기

1-Pager는 여행 계획서와 같다. 목적지(투자 이유), 경로(밸류에이션), 비상 탈출 계획(손절 기준), 날씨 예보(리스크)를 미리 정리해야 길을 잃지 않는다. 계획 없이 떠나는 여행은 모험이 되지만, 계획 없이 하는 투자는 도박이 된다.

## 실제 시장에서는

헤지펀드의 포트폴리오 매니저는 신규 종목을 추가하기 전 반드시 투자 메모(Investment Memo)를 작성하고 투자위원회의 승인을 받는다. 개인 투자자에게는 위원회가 없으므로, 1-Pager가 자기 자신을 설득하는 위원회 역할을 한다. 1-Pager를 쓰고 24시간 뒤에 다시 읽어보면, 흥분이 가라앉은 상태에서 논리의 빈틈을 발견할 수 있다.

## 흔한 오해

**"감이 좋으면 1-Pager 없이도 된다."** 인간의 기억은 자신에게 유리한 방향으로 왜곡된다. "처음부터 좋은 느낌이었어"라고 기억하지만, 실제로는 불안했던 부분을 잊은 것이다. 문서로 남겨야 나중에 정확하게 복기할 수 있고, 같은 실수를 반복하지 않을 수 있다.

**"너무 분석적이면 기회를 놓친다."** 1-Pager 작성에 2~3시간이면 충분하다. 수천만원 이상을 투자하면서 2~3시간의 분석을 '과도하다'고 느끼는 것이 오히려 비합리적이다. 50만원짜리 가전제품을 살 때도 리뷰를 찾아보는데, 500만원 이상의 투자에는 더 신중해야 하지 않겠는가.
